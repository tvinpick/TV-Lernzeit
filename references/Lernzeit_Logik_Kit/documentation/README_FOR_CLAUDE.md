# Lernzeit LOGIK kit — full HD and standalone transparent images

Copy only `Game_Assets/` into Godot. The `Reference_Only/` images are **not game assets**.

All UI panels and shapes are text-free PNG with alpha. Render instructions, numbers, answers and focus navigation in Godot. The background is 1920x1080.

## JSON contracts
- `formen.json`: shape name and list of three object names, each matching `Logik_FormObject_<name>.png`.
- `unterschiede.json`: two files per pair and exactly 3 bounding boxes `[x,y,w,h]` relative to the **760x560 right image**. The left and right images are intentionally identical except inside these three regions.
- `reihenfolge.json`: three frames in chronological order per story. Shuffle cards for exercises but retain solution order.
- Pattern rows (ABAB, AABB, ABC, etc.) should be generated by Godot rather than stored as images.

## TV / accessibility
Large focus frame, OK to confirm, arrows to switch. Keep text programmatic. Do not stretch 760x560 scenes non-uniformly. Show `Slot_Missing` with a Godot-rendered question-mark label; no text is baked into sprites.

## Important
Illustrations are clean original vector-like artwork for this build (rather than exact copies of the earlier illustration set); please check aesthetics on the target Sony TV.
