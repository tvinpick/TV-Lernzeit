# Lernzeit — Deutsch new word images (partial package 1)

**Status:** 24 of the newly requested words, focused on underrepresented initials C, J, Q, V, X, Y, Z, Ä, Ö and Ü. Not the full A–Z 3-per-letter set yet.

- Use only files in `Game_Assets/` in Godot.
- All objects are individual 400×400 RGBA PNG assets, with transparent corners.
- `Game_Assets/Data/deutsch_words_part1.json` maps word, letter, picture.
- `Reference_Only` is for visual review only.
- Source: a 5×5 concept sheet; objects were extracted with automated alpha cleanup. PLEASE VISUALLY CHECK edges and details before production import.
- These images are drafts from sheet crops, not 24 independently redrawn source artworks. Some thin lines and white details may have imperfect edges.
- For first-phoneme exercises: German letter names and pronunciation are not always identical. Especially C, Q, X and Y need review before speech exercises; these words are suitable more for letters/word recognition than a strict one-phoneme mapping.
