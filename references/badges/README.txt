LERNZEIT — ACHIEVEMENT BADGES v1

12 standalone 400x400 PNG RGBA achievement medals for Godot.
Folder: Mascot/Badges/
Transparent corners; approximately 5% transparent margin; no solid backgrounds.
Each medal represents one achievement. All dynamic titles and counters should be rendered in Godot, not on sprites.
The letters_8 medal contains A B C on toy blocks as explicitly requested.
Files are resized from original illustrations to 400x400 for TV performance.
Use id from ASSET_MANIFEST.json as stable achievement key.
Unlock logic is to be implemented in code; these are graphics only.

Achievement IDs:
- first_steps: Первый шаг — ботинок
- sessions_10: 10 занятий — стопка книг
- sessions_30: 30 занятий — кубок
- tasks_100: 100 заданий — ракета
- perfect: 10 из 10 — звезда с короной
- perfect_3: Три занятия без ошибок — три звезды
- days_3: Три дня — календарь с галочками
- days_7: Неделя — радуга
- math_trio: Математика — счёты
- math_20: Числа до 20 — лестница
- letters_8: Восемь букв — кубики ABC
- letters_19: 19 букв — сова в выпускной шапке
