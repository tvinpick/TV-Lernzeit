# Lernzeit — Mathematik / Vergleichen bis 10
## Full HD resource kit v2 | Sony BRAVIA 3 / Godot Android TV

### ВАЖНО: обновление стандарта производительности
- **ВСЕ фоны и концепт-экраны — 1920 × 1080**. В архиве нет файлов 4K.
- Кнопки и панели — компактные **RGBA PNG с настоящей прозрачностью**.
- 6 статичных макетов расположены в **Reference_Only** и экспортированы JPEG: они нужны Claude только как визуальный ориентир, не как часть игрового интерфейса.
- В `Game_Assets` находятся только предназначенные для приложения графические ресурсы.
- Числа, тексты, правильные ответы, прогресс и количество объектов **генерирует Godot**. Нельзя использовать иллюстрированные экраны как готовые упражнения.

### Как подключить к проекту Godot
1. Распакуй архив. Скопируй содержимое `Game_Assets/` в `res://assets/math/vergleichen_10/` (по необходимости согласуй имена с текущим проектом).
2. **Не копируй `Reference_Only/` в `res://`**, иначе Godot начнёт импортировать шесть полноэкранных картинок, которые не нужны во время игры.
3. Не дублируй существующие `math/shared_ui`: кнопки, яблоки, звёзды и числовые карточки можно переиспользовать, если они уже подключены.
4. Используй `Control` + `TextureRect` / `TextureButton`, предпочтительно `NinePatchRect` для масштабируемых панелей. Не масштабируй текст вместе с картинкой: текст отдельными `Label`.
5. Конфигурация базового UI: **1920×1080**, масштабирование на ТВ — программное. Сохраняй минимум 5% safe area, чтобы контент не обрезался экраном.
6. Подсветка фокуса — отдельная текстура `Compare_Focus_Ring_Transparent.png` или готовая focused-кнопка; D-pad и OK должны работать без мыши.
7. Индикатор прогресса динамический, **10 заданий в сессии**, включай вопросы с равенством (`=`) и одинаковыми количествами.

### Шесть типов заданий
| Type ID | Пример | Правильный ответ |
|---|---|---|
| `larger_number` | 7 или 4 | 7 |
| `smaller_number` | 3 или 8 | 3 |
| `comparison_sign` | 8 ? 5 | `>` |
| `compare_groups` | 4 и 7 яблок | правая группа |
| `equal_quantities` | по 6 звёзд | Ja |
| `sort_numbers` | 8, 2, 5 | 2, 5, 8 |

### Логика
- Диапазон на старте: 0–10 включительно. Сложность определяется параметром `max_number`, а не отдельной сценой для каждого уровня.
- Порядок вариантов ответов случайный, ответ с подсветкой на макете НЕ означает, что он всегда правильный.
- Сравнивай группы одинаковых объектов и одинакового масштаба. Для уровня 20+ используй десятки и единицы, а не десятки отдельных предметов.
- Для упорядочивания предоставь вариант выбора готовой последовательности с D-pad. Перетаскивание только мышкой/тачем не подходит.
- Сохраняй статистику по каждому типу тренировки и диапазону.
- Язык интерфейса: `Deutsch` по умолчанию, русский — вторым вариантом. Сам материал по немецкому языку при переключении интерфейса не должен искажаться.

### Ограничение по исходникам
Шесть концептов первоначально были нарисованы в 1672×941 и приведены к 1920×1080 методом качественной интерполяции. Фон уменьшен с 3840×2160. Изменение размера не добавляет новых художественных деталей, но игровые файлы больше не содержат 4K-текстур.

### Дополнительные замечания по оптимизации
- PNG хорошо сжимается на диске, но в памяти 1920×1080 RGBA — примерно **7.9 МиБ**; 3840×2160 RGBA — около **31.6 МиБ**. Поэтому не загружай 4K исходники.
- Используй один совместно разделяемый background, не создавай копию на каждую сцену.
- Текст и контрольные элементы рисуй по требованию. Не храни весь экран одним PNG.
- Размеры спрайтов в архиве — исходные для импорта; фактическая ширина и высота виджетов задаются через anchors/containers.
