LERNZEIT — MASCOT OWL v1

Contains 6 independent transparent PNG RGBA files, 800 x 800 px.

Mascot/Mascot_Owl_Idle.png      — neutral standing pose
Mascot/Mascot_Owl_Happy.png     — wings raised, happy
Mascot/Mascot_Owl_Thinking.png  — thinking pose
Mascot/Mascot_Owl_Cheer.png     — jumping celebration
Mascot/Mascot_Owl_Sleep.png     — sleeping on cushion (for rest prompt)
Mascot/Mascot_Owl_Wave.png      — waving

CHARACTER: The same brown-and-cream schoolgirl owl with round purple glasses,
a purple graduation cap, gold tassel, pink bow, purple cape and gold star.
No text, letters, numbers, backdrop or neighboring objects appear in PNGs.

IN GODOT: Each sprite is one TextureRect or Sprite2D asset.
Use center-bottom alignment for standing poses; for sleep position by eye on the
screen since the cushion changes visual baseline. Display at reduced size in UI.
Sprites were extracted from a cohesive six-pose illustration and upscaled to
800x800 canvas, so raster detail is limited by the sheet's source resolution.
A detailed manifest is in ASSET_MANIFEST.json.
Contact sheet preview is for reference ONLY, not for Godot import.
