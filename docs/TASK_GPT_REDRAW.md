# Задание для GPT — перерисовать «простые» картинки в общем стиле Lernzeit

Большинство картинок приложения нарисованы в одном красивом стиле: **яркая глянцевая мультяшная графика,
мягкий объём, блики, плавные переходы, милые лица** (как сова, «Löwe», «Igel», «Tomate», «Sonne» из
Lesen, «Zebra», «Qualle»). Часть картинок из последних наборов получилась **плоской, «как в Paint»**:
простые круги, одноцветные заливки, нет объёма. Их нужно **перерисовать в общем стиле**.

**Образцы стиля** (что должно получиться) — в репозитории:
`lernzeit/assets/deutsch/words/Deutsch_L_Loewe.png`, `Deutsch_I_Igel.png`, `Deutsch_Q_Qualle.png`,
`Deutsch_Z_Zebra.png`, `lernzeit/assets/lesen/words/Lesen_Sonne.png`, `Lesen_Tomate.png`,
`lernzeit/assets/mascot/owl/Mascot_Owl_Happy.png`, `lernzeit/assets/backgrounds/main_background_1080p.png`.

## Правила
- **Те же имена файлов и те же размеры**, что указаны ниже — тогда новые картинки просто заменят старые,
  код менять не нужно.
- PNG RGBA с **настоящей прозрачностью** (кроме фонов и сцен — они непрозрачные).
- **Никакого текста и цифр** на картинках.
- Тот же **смысл и тот же предмет**, что сейчас (картинка должна однозначно подходить к своему слову/предложению).
- Каждый архив: `Game_Assets/` (файлы с теми же именами), `Reference_Only/overview.jpg`, `documentation/README_FOR_CLAUDE.md`.
