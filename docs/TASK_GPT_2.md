# Задание для GPT (часть 2) — больше разнообразия для Lernzeit

Приложение уже работает полностью: все темы 1-го класса (Mathematik, Deutsch, Lesen, Logik),
озвучка голосом Nele, уровни, достижения, наклейки, контрольные, мини-игра.
Теперь нужно **больше материала**, чтобы задания не повторялись и ребёнку не было скучно.

## Общие правила (как раньше)
- Стиль — **как у первых наборов**: яркая глянцевая мультяшная графика с мягким объёмом и бликами
  (как сова, буквы, слова «Apfel», «Maus»), а **не** плоская векторная графика.
- PNG RGBA с настоящей прозрачностью; **никакого текста и цифр на картинках**.
- Имена файлов латиницей, без пробелов и умлаутов: `Loewe`, `Tuer`, `Fuss`, `Aepfel`.
- Каждый архив: `Game_Assets/`, `Reference_Only/` (макеты, JPEG), `documentation/README_FOR_CLAUDE.md`
  + `ASSET_MANIFEST.json`; все данные заданий — в JSON внутри `Game_Assets/Data/`.
- Немецкие тексты проверить на ошибки (артикли, заглавные буквы существительных, умлауты).
- Озвучка: голос **HeyGen «Nele — Friendly & Natural»**. Лучше сразу **готовые WAV** (PCM 16 bit, моно,
  44 100 Гц), а не ссылки: ссылки могут устареть. Скорость генерации 0.9, **без** дополнительного замедления.

## Приоритет 1 — то, что повторяется чаще всего

### 1.1 Слова для «Deutsch» (буквы и первый звук) — `Lernzeit_Deutsch_Words_2.zip`
Сейчас у многих букв только 2 слова, а у **C, J, Q, V, X, Y, Z, Ä, Ö, Ü — ни одного**.
- По **3 новых слова на каждую букву** A–Z (≈ 75 картинок, 400×400): только понятные первокласснику
  **предметы и животные**, которые начинаются с этой буквы и этого звука. Примеры:
  Clown, Computer · Jacke, Joghurt · Qualle · Vase · Xylofon · Yak · Zebra, Zahn, Zitrone.
- Для Ä, Ö, Ü — по 2 слова с этой буквой в начале: Äpfel, Ärmel · Öl, Ölkanne · Ufo-ähnliche ошибки не делать:
  нужен именно звук «ü» (Überraschungsei, Übernachtung — слишком сложно; лучше Übungsheft, Überhose — подобрать сами
  простые и проверить).
- JSON: `[{ "word": "Zebra", "letter": "Z", "picture": "Deutsch_Z_Zebra.png" }, …]`.
- Озвучка: `word_<Wort>` для каждого слова.

### 1.2 Слова для «Lesen · Silben/Wörter» — `Lernzeit_Lesen_Words_2.zip`
Сейчас 20 слов. Нужно **ещё 30**: 2–3 слога, простые открытые слоги (Ho-se, Na-se, Ba-na-ne, Mö-we, Tu-be…).
- 400×400 картинка + JSON `{ "word": "Möwe", "syllables": ["Mö", "we"], "picture": "Lesen_Moewe.png" }`.
- Озвучка: `word_<Wort>` и **все новые слоги** `syl_<слог>` (строчными, как раньше).

### 1.3 «Lesen · Texte» — ещё 12 мини-текстов — `Lernzeit_Lesen_Texte_2.zip`
Сейчас только 8 (ребёнок быстро запомнит). Формат как в `texte.json`: 2–3 предложения, вопрос,
3 картинки-ответа (300×300), `correct`. Озвучка `text_t09…t20` (текст + вопрос).

## Приоритет 2 — разнообразие

### 2.1 Ещё 30 предложений для «Sätze» — `Lernzeit_Lesen_Saetze_2.zip`
Формат как `saetze.json` (`s31…s60`), сцены 480×360. **Не делать похожих пар** (утка/гусь, роза/цветок):
каждая сцена должна однозначно подходить только к своему предложению. Озвучка `satz_s31…s60`.

### 2.2 Текстовые задачи до 20 — `Lernzeit_Textaufgaben_2.zip`
30 задач **с ответами 11–20** (`ta_31…ta_60`) и ещё 10 предметов (200×200): Erdbeere, Kastanie,
Murmel, Stift, Keks, Seifenblase, Biene, Schnecke, Muschel, Blatt. Озвучка каждой задачи.

### 2.3 Предметы для счёта в математике — `Lernzeit_Math_Objects_2.zip`
Сейчас считаем в основном яблоки, звёзды и шарики. Нужно **12 предметов** 200×200 в одном стиле:
Erdbeere, Birne, Karotte, Ente, Fisch, Schmetterling, Marienkäfer, Blume, Ball, Auto, Muschel, Keks.

### 2.4 Logik в «глянцевом» стиле — `Lernzeit_Logik_Kit_2.zip`
Картинки последнего набора Логики получились **плоскими и простыми** по сравнению с остальным приложением.
- **8 пар «Найди отличия»** заново в глянцевом стиле (760×560, ровно 3 заметных отличия, JSON с рамками —
  как `unterschiede.json`) + **8 новых пар**.
- **6 новых историй** для «Reihenfolge» по 3 кадра (360×360): Zähneputzen, Apfelbaum (Blüte → grüner
  Apfel → roter Apfel), Kaulquappe → Frosch, Kerze (neu → halb → aus), Brot backen, Haare schneiden.
- **Фон** Логики 1920×1080 в стиле остальных фонов (сейчас взят перекрашенный фон «Deutsch»).

## Озвучка (Nele) для всего выше
Отдельный архив `Lernzeit_Nele_Voice_3_WAV.zip` с **готовыми WAV** и `phrases.tsv` (`file / text / duration`):
- все новые `word_*`, `syl_*`, `satz_*`, `text_*`, `ta_*`;
- мини-игра: `game_target` («Lass alle Ballons mit … platzen!») — **без** числа/буквы в конце
  (приложение само добавит `num_*` / `letter_*`), `game_done` («Super gespielt!»);
- подсказки без записи: `tip_de_find` («Schau genau auf die Form von …»), `tip_de_build`, `tip_le_word_pic`,
  `tip_le_pic_word`, `tip_lg_muster`, `tip_lg_formen`, `tip_lg_reihenfolge`, `tip_lg_unterschiede`, `tip_zr`,
  `tip_equal`, `tip_le_satz`, `tip_le_text`, `tip_ta_plus`, `tip_ta_minus` (тексты — в `lernzeit/localization/de.json`);
- `goal_done` («Tagesziel geschafft! Toll!»), `limit` («Für heute ist Schluss! … Morgen geht es weiter.»),
  `lg_prompt_thing_form` («Welche Form hat das?»), `lg_prompt_middle` («Was passiert dazwischen?»).

## Как проверить перед отправкой
- Каждая картинка — на тёмном и на светлом фоне: нет белой подложки, края не обрезаны.
- Все файлы из JSON есть в `Game_Assets`, и наоборот.
- В «Sätze» и «Texte» среди трёх вариантов ответа нет двух подходящих.
- WAV прослушаны: нет обрезанных начал/концов, слова произнесены правильно.
